The star ladder, now honest about “mastered”

A star only lights as mastered — and counts toward the “illuminated” total teachers read — when the engine confirms mastery: pMastery ≥ 0.85 and a 3-correct streak. The new Confirming rung holds the “very likely, one more to lock it in” stars so they stay bright without being counted early.

lit / counted = pMastery ≥ 0.85 && correctStreak ≥ 3  ·  confirming = over the bar, streak < 3
  • One definition of mastered. The illumination count now matches what the practice engine believes — no more “3/3 illuminated” while the loop still assigns those skills.
  • The gradient stays rich. A near-mastered star doesn’t collapse back into the generic igniting tier — it charges through Confirming (a near-full cyan ring, gently pulsing) first.
  • Confirming is not counted. Only Lit and Fading (a mastered star due for review) count toward illumination.
