## Objective

Implement MAIS-MVP AgentOps v1 as an independent, repo-local, read-only control
plane. It compiles a host-produced `AgentOpsRequestV1` into a canonical task
contract, performs only registered read-only discovery and deterministic checks,
routes to exactly one A01-A25 primary lane, prepares specialist/evaluation plans,
and writes a redacted, resumable handoff under ignored `.local/agentops/` state.

## Security and integrity review

- Scope paths reject absolute paths, URLs, Windows paths, backslashes, empty or
  dot segments, and parent traversal.
- `.local/agentops` state parents and artifact files reject symlinks, escapes,
  non-regular files, and multi-link artifacts. Fixed policy files reject
  symlinks/escapes; specialist symlink markers remain unavailable.
- Atomic file writes use mode `0600`, `fsync`, and rename. A short mutation lock
  protects individual writes; a separate execution lock covers the whole run or
  resume and rejects a second executor.
- Manifest fields are exact; event directories reject unknown entries and
  missing history; contract, manifest, handoff, and current repository identity
  are cross-bound. A recomputed self-valid but contract-inconsistent handoff is
  rejected.
- Handoff permitted effects must exactly equal requested v1-safe effects, and
  next owner must equal the routed primary lane (or `owner` when unresolved).
- Release ordering is A25 read-only hygiene/intake before the A22 GraphOps
  handoff. Content ordering remains A21 candidate -> machine packet -> A18
  independent review -> A23 promotion -> A11 regression -> A22 release handoff;
  no step starts automatically.
