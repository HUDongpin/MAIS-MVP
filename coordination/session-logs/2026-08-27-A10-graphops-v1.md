## Assigned slice

Implement only the owner-approved MAIS GraphOps Foundation v1 contracts as a
reviewable, fail-closed slice: versioned graph definition and runner registry,
JSON-safe manifest/state/receipt/approval contracts, deterministic digests,
data-only evidence guards, a fixture-only LangGraph interrupt tracer, setup-only

arbitrary runner injection, public resume authority, Preview activation, and

contract gate in the existing CI validation job, and extends the frozen
release-governance package delta. The existing manual production workflow was
not deleted or repurposed by this session.

Real external activation is outside this code slice: GraphOps Preview and
Production capabilities remain disabled until A19 supplies an independent

specified pilot evidence. No product `POSTGRES_URL`, Vercel deployment, schema

by this implementation session.
