# 2026-06-30 A12 Lesson Progress Projection Batching

Agent: A12 backend/API platform lead

## Objective

Resolve the production `POST /api/lesson-progress` 500 captured by lesson smoke after the A05 audio-staticization work. The issue is independent from `/api/lesson-audio`.

## Root Cause

Production Vercel logs for `/api/lesson-progress` showed `MAX_PARAMETERS_EXCEEDED: Max number of parameters (65534) exceeded`.

The route calls `updateLessonProgress`, which persists the small lesson-progress mutation and then runs the Postgres projection shadow sync from `syncPostgresProjectionTablesWith`. The `projection_questions` full-table bulk insert had 23,753 rows and 7 inserted columns, which would create 166,271 parameters in one statement.

## Changes

- Added a Postgres projection batch-size helper capped at 65,000 parameters per statement.
- Routed all `syncPostgresProjectionTablesWith` projection bulk inserts through the batching helper.
- Added a regression assertion that `projection_questions` no longer uses one full-table statement.
