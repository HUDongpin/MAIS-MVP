# S18 Decision - us-ca-math-grade1-h-l-micro-lessons-v1

Status: approved-for-integration-review.

S18 accepts this package for live lesson integration because it provides 12 individual California Grade 1 MAIS knowledge-point lessons, preserves the requested systematic codes (`1-H.1` through `1-H.6`, `1-L.1` through `1-L.6`), uses distinctive MAIS-owned lesson names, and avoids copied IXL item text, preview wording, screenshots, and source titles in student-visible lesson content.

The package is English-primary and text-only. Future picture or cube-train visuals must be created as MAIS-owned assets and must pass the appropriate visual/exact-layer QA workflow before release.
