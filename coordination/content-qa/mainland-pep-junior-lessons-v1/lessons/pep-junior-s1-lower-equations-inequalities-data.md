## 简体中文教材

### 引入
有些问题不只需要一个未知数，有些答案不是一个数，而是一组满足条件的数。

### 学习目标
1. 用两个未知数建立二元一次方程组。
2. 解一元一次不等式并在数轴上表示解集。
3. 从小数据集中提出有根据的结论。

### 预备热身
若 \(x+y=12\) 且 \(x-y=4\)，猜一组满足两个等式的数。

### 核心讲解
方程组的解必须同时满足每个方程。不等式描述范围，乘除负数时不等号方向要改变。数据分析时，结论不能超过数据能支持的范围；样本、统计图和平均数都要服务于问题本身。

### 例题精讲
例1 例1：二元一次方程组
两种票共 \(18\) 张，总价 \(132\) 元。学生票 \(6\) 元，成人票 \(10\) 元。求两种票各多少张。
设学生票 \(x\) 张，成人票 \(y\) 张。列 \(x+y=18\)，\(6x+10y=132\)。由 \(x=18-y\) 代入，得 \(6(18-y)+10y=132\)，所以 \(y=6\)，\(x=12\)。
检查: \(12+6=18\)，\(6\times12+10\times6=132\)，都符合。

例2 例2：不等式解集
解不等式 \(-2x+5<13\)。
两边减 \(5\) 得 \(-2x<8\)。两边除以 \(-2\) 时不等号改变方向，得 \(x>-4\)。
检查: 取 \(x=0\)，原式 \(5<13\) 成立；取边界 \(x=-4\)，原式等于 \(13\)，不满足严格小于。

### 常见错误
1. 方程组只检查了一个方程。
2. 除以负数时忘记改变不等号方向。
3. 用样本数据推出过大的结论。

### 误区诊断
1. 若学生把 \(-3x>9\) 解成 \(x> -3\)，请让他用 \(x=0\) 检查原不等式。
2. 若学生说某调查代表所有学生，请追问样本来自哪里、人数是否足够。

### 策略清单
1. 方程组先定义两个未知数。
2. 解完方程组要代回两个方程。
3. 不等式乘除负数要换方向。
4. 数据结论要写依据和限制。

### 小练习
小练习 1: 解 \(x+2y=11\)，\(x=3\) 时 \(y\) 是多少？
答案: 4. 代入得 \(3+2y=11\)，所以 \(2y=8\)，\(y=4\)。
小练习 2: 解不等式 \(4x-1\ge 15\)。
答案: x>=4. 两边加 \(1\) 得 \(4x\ge16\)，所以 \(x\ge4\)。
小练习 3: 一组数据为 \(5,7,7,9\)，平均数是多少？
答案: 7. \((5+7+7+9)\div4=7\)。

### 考试策略
模型题先写变量含义和限制；不等式题先标边界，再用测试值确认方向。

### 拓展任务
设计一个班级问卷小数据集，计算一个统计量，并写一句有边界的结论。

### 出门票
解 \(-x<2\) 时，为什么答案是 \(x>-2\)？

### 术语表
方程组: 需要同时满足的多个方程。
解集: 所有满足条件的数或数对。
不等式: 用大于、小于等关系表示范围的式子。
样本: 从总体中选取的一部分数据。

## English Lesson Textbook

### Hook
Some problems need more than one unknown, and some answers are not one number but a set of values that satisfy a condition.

### Objectives
1. Build a two-variable linear system from a situation.
2. Solve a one-variable linear inequality and represent the solution set on a number line.
3. Draw justified conclusions from a small dataset.

### Prerequisite Warm-Up
If \(x+y=12\) and \(x-y=4\), guess a pair of numbers satisfying both equations.

### Core Concept
A solution of a system must satisfy every equation in the system. An inequality describes a range, and multiplying or dividing by a negative number reverses the inequality sign. In data analysis, conclusions cannot go beyond what the data support; samples, graphs, and averages must serve the question being asked.

### Worked Examples
Example 1 Example 1: Linear System
There are \(18\) tickets costing \(132\) yuan in total. A student ticket costs \(6\) yuan and an adult ticket costs \(10\) yuan. How many of each ticket were bought?
Let \(x\) be student tickets and \(y\) be adult tickets. Write \(x+y=18\) and \(6x+10y=132\). From \(x=18-y\), substitute to get \(6(18-y)+10y=132\), so \(y=6\) and \(x=12\).
Check: \(12+6=18\) and \(6\times12+10\times6=132\), so both conditions hold.

Example 2 Example 2: Inequality Solution Set
Solve \(-2x+5<13\).
Subtract \(5\) from both sides to get \(-2x<8\). Dividing by \(-2\) reverses the inequality sign, giving \(x>-4\).
Check: Try \(x=0\): \(5<13\) is true. At boundary \(x=-4\), the expression equals \(13\), which does not satisfy strict less than.

### Common Pitfalls
1. Checking only one equation in a system.
2. Forgetting to reverse the inequality sign when dividing by a negative number.
3. Making a conclusion larger than the sample supports.

### Misconception Clinic
1. If a learner solves \(-3x>9\) as \(x>-3\), ask them to test \(x=0\) in the original inequality.
2. If a learner says a survey represents all students, ask where the sample came from and whether it is large enough.

### Strategy Checklist
1. Define two unknowns first for a system.
2. After solving, substitute into both equations.
3. Reverse the sign when multiplying or dividing an inequality by a negative number.
4. Write the evidence and limitation for a data conclusion.

### Checkpoints
Checkpoint 1: If \(x+2y=11\) and \(x=3\), what is \(y\)?
Answer: 4. Substitute to get \(3+2y=11\), so \(2y=8\) and \(y=4\).
Checkpoint 2: Solve \(4x-1\ge 15\).
Answer: x>=4. Add \(1\) to both sides to get \(4x\ge16\), so \(x\ge4\).
Checkpoint 3: For the data \(5,7,7,9\), what is the mean?
Answer: 7. \((5+7+7+9)\div4=7\).

### Exam-Style Strategy
For modeling tasks, write variable meanings and restrictions first. For inequalities, mark the boundary and use test values to confirm direction.

### Extension
Design a small class survey dataset, compute one statistic, and write one conclusion with a clear limitation.

### Exit Ticket
When solving \(-x<2\), why is the answer \(x>-2\)?

### Glossary
system of equations: Several equations that must be satisfied at the same time.
solution set: All numbers or pairs that satisfy a condition.
inequality: A statement describing a range using greater-than or less-than relationships.
sample: A subset of data selected from a larger population.
