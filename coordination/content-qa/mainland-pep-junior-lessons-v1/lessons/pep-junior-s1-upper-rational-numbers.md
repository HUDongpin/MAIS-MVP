## 简体中文教材

### 引入
同一个数字在不同方向上可以表示上升、下降、收入或支出。数轴让这些变化有了可观察的位置。

### 学习目标
1. 解释正数、负数和零在实际情境中的意义。
2. 在数轴上比较有理数并说明理由。
3. 用相反数、绝对值和运算检查结果是否合理。

### 预备热身
从 \(0\) 出发，向右走 \(4\) 格，再向左走 \(7\) 格。说出终点，并解释每一步的方向。

### 核心讲解
有理数可以放在数轴上比较。数轴上越靠右的数越大；相反数到 \(0\) 的距离相同但方向相反；绝对值表示一个数到 \(0\) 的距离，所以 \(|-5|=5\)。运算时先判断方向，再用距离完成计算。

### 例题精讲
例1 例1：温度变化
清晨温度为 \(-3^\circ C\)，中午升高 \(8^\circ C\)，傍晚又下降 \(5^\circ C\)。傍晚温度是多少？
先算 \(-3+8=5\)，再算 \(5-5=0\)。所以傍晚温度为 \(0^\circ C\)。
检查: 在数轴上从 \(-3\) 向右 \(8\) 格到 \(5\)，再向左 \(5\) 格回到 \(0\)。

例2 例2：比较大小
比较 \(-\frac{3}{4}\)、\(-0.6\) 和 \(0.2\) 的大小。
把 \(-\frac{3}{4}\) 写成 \(-0.75\)。数轴上 \(-0.75\) 在 \(-0.6\) 左边，\(0.2\) 在右边，所以 \(-\frac{3}{4}<-0.6<0.2\)。
检查: 负数比较时，离 \(0\) 越远反而越小。

### 常见错误
1. 把负号当作减号，忽略它也能表示方向。
2. 认为绝对值会保留原来的正负号。
3. 比较两个负数时只看数字大小，不看数轴位置。

### 误区诊断
1. 若学生说 \(-8>-3\)，请让他在数轴上标出两个点并读左右位置。
2. 若学生写 \(|-6|=-6\)，请强调绝对值回答的是距离，而距离不为负。

### 策略清单
1. 先判断数表示方向、位置还是变化量。
2. 比较大小时先想数轴左右。
3. 含绝对值时先说距离，再写数值。
4. 运算后用情境或数轴检查结果。

### 小练习
小练习 1: 计算 \(-6+11-4\)。
答案: 1. 先得 \(-6+11=5\)，再得 \(5-4=1\)。
小练习 2: 比较 \(-2.5\) 和 \(-2.05\)，哪个更小？
答案: -2.5. \(-2.5\) 在数轴上更靠左，所以更小。
小练习 3: 写出 \(7\) 的相反数和 \(|-7|\) 的值。
答案: -7; 7. \(7\) 的相反数是 \(-7\)；\(|-7|\) 表示到 \(0\) 的距离，是 \(7\)。

### 考试策略
遇到含负数的综合题，先把每个数量标成位置或变化量，再决定加、减和比较方向。

### 拓展任务
设计一条校园积分记录，至少包含三次加分和两次扣分，并用数轴解释最终积分。

### 出门票
一句话说明为什么 \(|-9|\) 不是 \(-9\)。

### 术语表
有理数: 能写成整数或分数形式的数。
数轴: 用位置表示数大小和方向的直线。
相反数: 到零距离相同、方向相反的两个数。
绝对值: 一个数到零的距离。

## English Lesson Textbook

### Hook
The same number can describe a rise, a fall, income, or spending depending on direction. A number line makes these changes visible.

### Objectives
1. Explain the meaning of positive numbers, negative numbers, and zero in real situations.
2. Compare rational numbers on a number line and justify the comparison.
3. Use opposites, absolute value, and operations to check whether an answer is reasonable.

### Prerequisite Warm-Up
Start at \(0\). Move \(4\) steps right, then \(7\) steps left. Name the endpoint and explain each direction.

### Core Concept
Rational numbers can be compared on a number line. Numbers farther right are greater. Opposite numbers have the same distance from \(0\) but opposite directions. Absolute value is distance from \(0\), so \(|-5|=5\). In operations, decide the direction first, then use distance to complete the calculation.

### Worked Examples
Example 1 Example 1: Temperature Change
The morning temperature is \(-3^\circ C\). It rises by \(8^\circ C\) at noon and then falls by \(5^\circ C\) in the evening. What is the evening temperature?
First compute \(-3+8=5\), then \(5-5=0\). The evening temperature is \(0^\circ C\).
Check: On the number line, move from \(-3\) right \(8\) steps to \(5\), then left \(5\) steps back to \(0\).

Example 2 Example 2: Compare Values
Compare \(-\frac{3}{4}\), \(-0.6\), and \(0.2\).
Write \(-\frac{3}{4}\) as \(-0.75\). On the number line, \(-0.75\) is left of \(-0.6\), and \(0.2\) is to the right, so \(-\frac{3}{4}<-0.6<0.2\).
Check: For negative numbers, the one farther from \(0\) is smaller.

### Common Pitfalls
1. Treating a negative sign only as subtraction and missing its direction meaning.
2. Thinking absolute value keeps the original sign.
3. Comparing two negative numbers by digit size instead of number-line position.

### Misconception Clinic
1. If a learner says \(-8>-3\), ask them to mark both points and read left-to-right position.
2. If a learner writes \(|-6|=-6\), emphasize that absolute value answers a distance question, and distance is not negative.

### Strategy Checklist
1. First decide whether the number represents direction, position, or change.
2. When comparing, picture left and right on the number line.
3. For absolute value, state the distance before writing the value.
4. After computing, check the answer with the context or number line.

### Checkpoints
Checkpoint 1: Compute \(-6+11-4\).
Answer: 1. First \(-6+11=5\), then \(5-4=1\).
Checkpoint 2: Compare \(-2.5\) and \(-2.05\). Which is smaller?
Answer: -2.5. \(-2.5\) is farther left on the number line, so it is smaller.
Checkpoint 3: Write the opposite of \(7\) and the value of \(|-7|\).
Answer: -7; 7. The opposite of \(7\) is \(-7\); \(|-7|\) is the distance from \(0\), which is \(7\).

### Exam-Style Strategy
For mixed signed-number tasks, first label each quantity as a position or a change, then choose addition, subtraction, and comparison direction.

### Extension
Design a school-points record with at least three gains and two deductions, then explain the final score on a number line.

### Exit Ticket
In one sentence, explain why \(|-9|\) is not \(-9\).

### Glossary
rational number: A number that can be written as an integer or a fraction.
number line: A line that represents size and direction by position.
opposite number: Two numbers with the same distance from zero and opposite directions.
absolute value: The distance of a number from zero.
