## 简体中文教材

### 引入
同一张图既可以用角关系解释，也可以用坐标表示位置变化。

### 学习目标
1. 识别邻补角、对顶角和平行线角关系。
2. 在平面直角坐标系中定位点。
3. 解释水平或竖直平移对坐标的影响。

### 预备热身
点 \(P(2,-3)\) 的横坐标和纵坐标分别是什么？它在第几象限？

### 核心讲解
相交线形成的对顶角相等，邻补角和为 \(180^\circ\)。平行线被截线所截时，同位角、内错角等关系需要先确认“两直线平行”。坐标点 \((x,y)\) 先读横坐标，再读纵坐标；沿水平方向移动改变 \(x\)，沿竖直方向移动改变 \(y\)。

### 例题精讲
例1 例1：角关系
两条直线相交。若一个角为 \(64^\circ\)，求它的对顶角和邻补角。
对顶角相等，所以为 \(64^\circ\)。邻补角与它和为 \(180^\circ\)，所以 \(180^\circ-64^\circ=116^\circ\)。
检查: 四个角应成两组相等角，且相邻两个角和为 \(180^\circ\)。

例2 例2：坐标平移
点 \(A(-2,5)\) 向右平移 \(6\) 个单位，再向下平移 \(3\) 个单位，得到点 \(A'\)。求 \(A'\) 坐标。
向右使 \(x\) 加 \(6\)：\(-2+6=4\)；向下使 \(y\) 减 \(3\)：\(5-3=2\)。所以 \(A'(4,2)\)。
检查: 右移不改变纵坐标之前的变化方向，下移不改变横坐标。

### 常见错误
1. 没有确认平行条件就使用内错角相等。
2. 把横坐标和纵坐标读反。
3. 把坐标轴上的点误判为某个象限内。

### 误区诊断
1. 若学生说 \((0,4)\) 在第一象限，请指出它在 \(y\) 轴上，不属于任何象限。
2. 若学生用平行线角关系，请要求先标出哪两条线平行。

### 策略清单
1. 角关系先看条件：相交还是平行。
2. 坐标先横后纵。
3. 轴上点不属于任何象限。
4. 平移时分别处理横坐标和纵坐标。

### 小练习
小练习 1: 若邻补角之一为 \(73^\circ\)，另一个是多少？
答案: 107 degrees. \(180^\circ-73^\circ=107^\circ\)。
小练习 2: 点 \(B(0,-5)\) 在哪个坐标轴上？
答案: y-axis. 横坐标为 \(0\)，所以点在 \(y\) 轴上。
小练习 3: 点 \(C(3,1)\) 向左 \(4\) 个单位后坐标是多少？
答案: (-1,1). 向左使 \(x\) 减 \(4\)，得 \(3-4=-1\)，所以为 \((-1,1)\)。

### 考试策略
几何坐标题先分层：先读角或平行条件，再读坐标和平移方向，避免把图像观察当作证明。

### 拓展任务
设计一条校园路线图，用坐标写出三个点的位置，并给出一次平移后的新坐标。

### 出门票
为什么使用内错角相等前必须知道两条直线平行？

### 术语表
对顶角: 两条直线相交形成的相对角。
邻补角: 相邻且和为一百八十度的两个角。
坐标: 表示点在平面中位置的有序数对。
平移: 图形按同一方向和距离移动。

## English Lesson Textbook

### Hook
The same figure can be explained by angle relationships and by coordinate changes.

### Objectives
1. Identify linear pairs, vertical angles, and parallel-line angle relationships.
2. Locate points in the coordinate plane.
3. Explain how horizontal or vertical translations affect coordinates.

### Prerequisite Warm-Up
For point \(P(2,-3)\), what are the x-coordinate and y-coordinate? Which quadrant is it in?

### Core Concept
Intersecting lines create equal vertical angles, and a linear pair sums to \(180^\circ\). When parallel lines are cut by a transversal, angle relationships such as corresponding and alternate interior angles require the condition that the two lines are parallel. In \((x,y)\), read the x-coordinate first and the y-coordinate second. Horizontal movement changes \(x\); vertical movement changes \(y\).

### Worked Examples
Example 1 Example 1: Angle Relationship
Two lines intersect. If one angle is \(64^\circ\), find its vertical angle and its adjacent supplementary angle.
The vertical angle is equal, so it is \(64^\circ\). The adjacent supplementary angle sums with it to \(180^\circ\), so \(180^\circ-64^\circ=116^\circ\).
Check: The four angles should form two equal pairs, and adjacent angles should sum to \(180^\circ\).

Example 2 Example 2: Coordinate Translation
Point \(A(-2,5)\) moves \(6\) units right and then \(3\) units down to point \(A'\). Find the coordinates of \(A'\).
Moving right adds \(6\) to \(x\): \(-2+6=4\). Moving down subtracts \(3\) from \(y\): \(5-3=2\). Thus \(A'(4,2)\).
Check: A right shift changes only the x-coordinate, and a down shift changes only the y-coordinate.

### Common Pitfalls
1. Using alternate interior angles without confirming parallel lines.
2. Reading x- and y-coordinates in the wrong order.
3. Putting a point on an axis into a quadrant.

### Misconception Clinic
1. If a learner says \((0,4)\) is in Quadrant I, point out that it lies on the \(y\)-axis and is in no quadrant.
2. If a learner uses a parallel-line angle relationship, ask them to mark which two lines are parallel first.

### Strategy Checklist
1. For angle relationships, inspect the condition: intersecting or parallel.
2. Read coordinates as x first, then y.
3. A point on an axis is not in a quadrant.
4. For translations, handle x- and y-coordinates separately.

### Checkpoints
Checkpoint 1: If one angle in a linear pair is \(73^\circ\), what is the other?
Answer: 107 degrees. \(180^\circ-73^\circ=107^\circ\).
Checkpoint 2: Which axis contains point \(B(0,-5)\)?
Answer: y-axis. The x-coordinate is \(0\), so the point lies on the \(y\)-axis.
Checkpoint 3: What are the coordinates after point \(C(3,1)\) moves \(4\) units left?
Answer: (-1,1). Moving left subtracts \(4\) from \(x\): \(3-4=-1\), so the point is \((-1,1)\).

### Exam-Style Strategy
For geometry-coordinate items, separate layers: read angle or parallel conditions first, then coordinates and translation directions. Do not treat visual appearance as proof.

### Extension
Design a campus route map, write the coordinates of three points, and give the new coordinates after one translation.

### Exit Ticket
Why must we know two lines are parallel before using equal alternate interior angles?

### Glossary
vertical angles: Opposite angles formed by two intersecting lines.
linear pair: Adjacent angles whose measures sum to one hundred eighty degrees.
coordinates: An ordered pair describing a point's position in the plane.
translation: A movement of a figure by the same direction and distance.
