## 简体中文教材

### 引入
当数量会变化时，字母可以把共同规律保留下来，方程则把相等关系写清楚。

### 学习目标
1. 用字母表示实际数量。
2. 合并同类项并解释每一步。
3. 建立并求解一元一次方程。

### 预备热身
若一支笔 \(x\) 元，三支笔和一本 \(5\) 元练习本共多少钱？

### 核心讲解
整式是用数、字母和运算组成的式子。同类项含有相同字母部分，例如 \(3a\) 和 \(-5a\)。一元一次方程只有一个未知数，且未知数最高次数为 \(1\)。解方程时，每一步都要保持等式两边平衡。

### 例题精讲
例1 例1：合并同类项
化简 \(4x-3+2x+9\)。
同类项分别合并：\(4x+2x=6x\)，\(-3+9=6\)，所以结果为 \(6x+6\)。
检查: 代入 \(x=1\)，原式为 \(12\)，化简式也为 \(12\)。

例2 例2：建立方程
一个数的 \(3\) 倍再减 \(7\) 等于 \(20\)。求这个数。
设这个数为 \(x\)，列方程 \(3x-7=20\)。两边加 \(7\) 得 \(3x=27\)，所以 \(x=9\)。
检查: 代回原关系：\(3\times9-7=20\)，成立。

### 常见错误
1. 把不同字母项合并。
2. 去括号时漏掉负号分配。
3. 解方程后没有代回检验。

### 误区诊断
1. 若学生把 \(2a+3b\) 写成 \(5ab\)，请让他说明 \(a\) 和 \(b\) 是否表示同一种数量。
2. 若学生从 \(2(x-4)\) 得到 \(2x-4\)，请用分配律重写为 \(2x-8\)。

### 策略清单
1. 先定义未知数。
2. 找出等量关系。
3. 每一步方程变形两边同做。
4. 最后代回原题检查。

### 小练习
小练习 1: 化简 \(7y-2y+5\)。
答案: 5y+5. \(7y-2y=5y\)，常数 \(5\) 保留。
小练习 2: 解方程 \(5x+4=19\)。
答案: 3. 两边减 \(4\) 得 \(5x=15\)，所以 \(x=3\)。
小练习 3: 把“比 \(n\) 的两倍多 \(6\)”写成代数式。
答案: 2n+6. 两倍是 \(2n\)，多 \(6\) 是 \(2n+6\)。

### 考试策略
应用题先圈出未知量、总量和比较关系，再把文字顺序转换成代数顺序。

### 拓展任务
把一个购物优惠情境写成方程，并解释方程每一项的实际意义。

### 出门票
为什么 \(3x+2x\) 可以合并，而 \(3x+2y\) 不可以？

### 术语表
整式: 由数、字母和运算组成的式子。
同类项: 字母部分完全相同的项。
一元一次方程: 只含一个未知数且最高次数为一的方程。
等式性质: 等式两边同做相同运算，等式仍成立。

## English Lesson Textbook

### Hook
When quantities vary, letters preserve the shared pattern, and equations make equality relationships clear.

### Objectives
1. Represent real quantities with letters.
2. Combine like terms and explain each step.
3. Build and solve one-variable linear equations.

### Prerequisite Warm-Up
If one pen costs \(x\) yuan, how much do three pens and one \(5\)-yuan notebook cost?

### Core Concept
An algebraic expression is built from numbers, letters, and operations. Like terms have the same letter part, such as \(3a\) and \(-5a\). A one-variable linear equation has one unknown, and the highest power of the unknown is \(1\). When solving, every step must preserve balance on both sides.

### Worked Examples
Example 1 Example 1: Combine Like Terms
Simplify \(4x-3+2x+9\).
Combine like terms: \(4x+2x=6x\) and \(-3+9=6\), so the result is \(6x+6\).
Check: Substitute \(x=1\). The original expression is \(12\), and the simplified expression is also \(12\).

Example 2 Example 2: Build an Equation
\(3\) times a number minus \(7\) equals \(20\). Find the number.
Let the number be \(x\). Write \(3x-7=20\). Add \(7\) to both sides to get \(3x=27\), so \(x=9\).
Check: Check in the original relationship: \(3\times9-7=20\), so it works.

### Common Pitfalls
1. Combining terms with different letter parts.
2. Dropping a negative sign when removing brackets.
3. Solving an equation without substituting back to check.

### Misconception Clinic
1. If a learner changes \(2a+3b\) into \(5ab\), ask whether \(a\) and \(b\) represent the same quantity.
2. If a learner changes \(2(x-4)\) into \(2x-4\), use the distributive property to show \(2x-8\).

### Strategy Checklist
1. Define the unknown first.
2. Find the equality relationship.
3. Perform the same operation on both sides.
4. Substitute the answer back into the original problem.

### Checkpoints
Checkpoint 1: Simplify \(7y-2y+5\).
Answer: 5y+5. \(7y-2y=5y\), and the constant \(5\) remains.
Checkpoint 2: Solve \(5x+4=19\).
Answer: 3. Subtract \(4\) from both sides to get \(5x=15\), so \(x=3\).
Checkpoint 3: Write "\(6\) more than twice \(n\)" as an expression.
Answer: 2n+6. Twice the number is \(2n\); \(6\) more is \(2n+6\).

### Exam-Style Strategy
For word problems, circle the unknown, total, and comparison relationship before translating text order into algebraic order.

### Extension
Write an equation for a shopping-discount situation and explain the real meaning of each term.

### Exit Ticket
Why can \(3x+2x\) be combined, but \(3x+2y\) cannot?

### Glossary
algebraic expression: An expression made of numbers, letters, and operations.
like terms: Terms with exactly the same letter part.
one-variable linear equation: An equation with one unknown whose highest power is one.
properties of equality: Doing the same operation to both sides keeps an equation true.
