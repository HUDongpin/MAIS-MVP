## 简体中文教材

### 引入
几何学习不是只看图像像不像，而是用准确语言说明对象是什么、关系是什么。

### 学习目标
1. 区分直线、射线和线段。
2. 用角的度量描述图形关系。
3. 用定义而不是外观判断几何对象。

### 预备热身
在纸上画两个点 \(A\)、\(B\)，分别画线段 \(AB\)、射线 \(AB\) 和直线 \(AB\)。

### 核心讲解
点表示位置，线段有两个端点，射线有一个端点并向一个方向无限延伸，直线向两个方向无限延伸。角由两条有公共端点的射线组成，角的大小由张开程度决定，而不是边画得多长。

### 例题精讲
例1 例1：读图形语言
点 \(A\)、\(B\)、\(C\) 在同一直线上，且 \(B\) 在 \(A\) 与 \(C\) 之间。若 \(AB=4\)，\(BC=7\)，求 \(AC\)。
\(B\) 在中间，所以整段 \(AC\) 由 \(AB\) 和 \(BC\) 组成：\(AC=4+7=11\)。
检查: 线段长度相加必须符合“中间点”条件。

例2 例2：判断角的大小
两个角分别为 \(35^\circ\) 和 \(53^\circ\)。哪一个更大？若图中 \(35^\circ\) 的边更长，会改变答案吗？
\(53^\circ\) 更大。角的大小由张开程度决定，边的长度不改变角度。
检查: 用量角器读数时看刻度，不看边长。

### 常见错误
1. 把射线和线段混淆。
2. 按图形外观猜结论，不看定义。
3. 认为角边越长，角越大。

### 误区诊断
1. 若学生说射线 \(AB\) 与射线 \(BA\) 相同，请让他指出各自端点和方向。
2. 若学生凭肉眼判断两角相等，请要求给出度量或已知条件。

### 策略清单
1. 先标出点、端点和方向。
2. 判断线类对象时说出端点个数。
3. 比较角时看度数或可证明关系。
4. 写结论前说明使用的定义。

### 小练习
小练习 1: 线段 \(PQ\) 有几个端点？
答案: 2. 线段有两个端点，分别是 \(P\) 和 \(Q\)。
小练习 2: 若 \(\angle A=28^\circ\)，\(\angle B=82^\circ\)，哪个角更大？
答案: angle B. \(82^\circ>28^\circ\)，所以 \(\angle B\) 更大。
小练习 3: 点 \(M\) 在线段 \(XY\) 上，\(XM=3\)，\(MY=9\)，求 \(XY\)。
答案: 12. \(XY=XM+MY=3+9=12\)。

### 考试策略
几何基础题先把题目语言翻译成图形标记，再确认能否用定义或已知条件推出结论。

### 拓展任务
拍一张教室物体照片，用点、线段、射线、直线和角写出五条准确描述。

### 出门票
说明为什么两个画得很长的角边不能直接证明角更大。

### 术语表
线段: 有两个端点的直线部分。
射线: 有一个端点并向一个方向延伸的线。
直线: 向两个方向无限延伸的线。
角: 由两条有公共端点的射线组成的图形。

## English Lesson Textbook

### Hook
Geometry is not just about what a drawing looks like; it is about using precise language to state objects and relationships.

### Objectives
1. Distinguish lines, rays, and segments.
2. Describe figure relationships using angle measure.
3. Use definitions rather than appearance to identify geometric objects.

### Prerequisite Warm-Up
Draw two points \(A\) and \(B\). Then draw segment \(AB\), ray \(AB\), and line \(AB\).

### Core Concept
A point represents a position. A segment has two endpoints. A ray has one endpoint and extends forever in one direction. A line extends forever in two directions. An angle is formed by two rays with a common endpoint, and its size depends on opening, not on how long the arms are drawn.

### Worked Examples
Example 1 Example 1: Read Geometric Language
Points \(A\), \(B\), and \(C\) lie on the same line, and \(B\) is between \(A\) and \(C\). If \(AB=4\) and \(BC=7\), find \(AC\).
\(B\) is between the endpoints, so segment \(AC\) is made of \(AB\) and \(BC\): \(AC=4+7=11\).
Check: Adding segment lengths is valid because the point-between condition is given.

Example 2 Example 2: Judge Angle Size
Two angles measure \(35^\circ\) and \(53^\circ\). Which is larger? If the arms of the \(35^\circ\) angle are drawn longer, does the answer change?
\(53^\circ\) is larger. Angle size depends on opening, so longer arms do not change the angle measure.
Check: When using a protractor, read the scale, not the arm length.

### Common Pitfalls
1. Confusing rays with segments.
2. Guessing conclusions from appearance instead of definitions.
3. Thinking a longer angle arm means a larger angle.

### Misconception Clinic
1. If a learner says ray \(AB\) and ray \(BA\) are the same, ask them to identify each endpoint and direction.
2. If a learner judges angles equal by sight, ask for a measure or given condition.

### Strategy Checklist
1. Mark points, endpoints, and directions first.
2. For line objects, state the number of endpoints.
3. Compare angles using measures or provable relationships.
4. Before writing a conclusion, name the definition used.

### Checkpoints
Checkpoint 1: How many endpoints does segment \(PQ\) have?
Answer: 2. A segment has two endpoints, \(P\) and \(Q\).
Checkpoint 2: If \(\angle A=28^\circ\) and \(\angle B=82^\circ\), which angle is larger?
Answer: angle B. \(82^\circ>28^\circ\), so \(\angle B\) is larger.
Checkpoint 3: Point \(M\) lies on segment \(XY\). If \(XM=3\) and \(MY=9\), find \(XY\).
Answer: 12. \(XY=XM+MY=3+9=12\).

### Exam-Style Strategy
For foundational geometry items, translate the text into figure markings first, then confirm whether a definition or given condition supports the conclusion.

### Extension
Take a photo of a classroom object and write five precise descriptions using points, segments, rays, lines, and angles.

### Exit Ticket
Explain why longer drawn angle arms do not prove that an angle is larger.

### Glossary
segment: Part of a line with two endpoints.
ray: A line part with one endpoint that extends in one direction.
line: A line extending without end in two directions.
angle: A figure formed by two rays with a common endpoint.
