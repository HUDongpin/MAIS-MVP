# Frozen sacrificial arm contracts

These contracts apply to the F2-R sacrificial fixture. They specify topology and receipts, not model quality. The formal campaign runner is intentionally absent.

Formal execution is disabled throughout F0-F2.

## Shared invariants

- Input is immutable and identified by SHA-256.
- Output is written by one writer into the run-specific outbox.
- Every surface ends as `finding`, `clean-with-evidence`, `unjudgeable`, or `not-inspected`.
- `unjudgeable` and `not-inspected` are never passes.
- Completion is false if mandatory surfaces are missing, hashes drift, a runner is skipped, or an open P0/P1 remains.
- No source, main, production, shared checkout, evaluator, or denominator mutation is allowed.
- The fixture contains 24 questions, two lessons, and zero browser routes. Browser rendering is excluded from the estimand; it is not a passed check.
- F2-R uses the deterministic no-charge adapter. Live-provider mode remains disabled.
- Each public snapshot and external attempt requires a final commit marker; a partial staging directory is not a completed attempt.

## A

Run deterministic inventory, answer consistency, accepted-form, MC uniqueness, static-evidence-label, lesson-example, duplicate, and provenance checks. Apply the fixed mandatory-surface sentinel. No reflective role is invoked.

## B

Run A, then one deterministic same-reviewer critique pass over A's receipt and one deterministic revision pass. The review may improve finding normalization and surface accounting but may not call a heterogeneous verifier.

## C0

Run the same five role tasks and tools as C through one serial controller with shared state: answer-blind solver, tool verifier, adversarial grader, bilingual/curriculum critic, and evidence verifier. Preserve per-role execution and surface accounting.

## C

Run the same five role tasks and tools as C0 in distinct child processes with a cleaned environment. Roles submit read-only findings to one writer. The writer deduplicates and emits the receipt. Only topology differs from C0. The separate A22 Seatbelt matrix proves the deny-default mechanism for the same five role identities; it remains candidate evidence pending independent A22 review.

## F2 interpretation

Passing the deterministic sacrificial fixture proves only that the contract, semantic validator, lifecycle, stop logic, and replay path execute. It does not prove a live model follows the contract, C outperforms C0, or any arm is ready for the formal 48 runs.
