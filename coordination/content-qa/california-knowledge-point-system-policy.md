# California Knowledge-Point Lesson System Policy

## Decision

California MAIS lessons should be organized at knowledge-point granularity, not only broad domain/topic granularity.

Each knowledge-point lesson should have:

- A stable code such as `1-H.1`, `1-H.2`, or the corresponding middle/high-school course code.
- A distinctive MAIS-owned public title, not a copied IXL skill title.
- Source metadata that may record IXL as a secondary navigation/alignment signal.
- Student-facing text, examples, prompts, explanations, and visuals that are MAIS-authored original content.
- Standard IDs from California/Common Core structure as metadata.
- S18 content QA, S05/S04 integration ownership, S11 route regression, and S22 release evidence before production claims.

## Source Boundary

IXL pages may be used to understand the code structure, grade navigation, and high-level skill organization. Do not copy IXL exercise previews, item wording, answer choices, screenshots, or proprietary activity sequences into MAIS.

## Grade-Span Scope

This policy applies to:

- Elementary California math lessons.
- Middle-school California math lessons.
- High-school California math lessons.

The first implemented package under this policy is `us-ca-math-grade1-h-l-micro-lessons-v1`.
