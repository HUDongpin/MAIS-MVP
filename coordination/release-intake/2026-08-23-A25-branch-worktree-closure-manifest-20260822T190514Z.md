## Interpretation rules

- Dirty worktrees are preserve-first regardless of whether their current commit is already in main.
- An open PR keeps the branch in OPEN_PR_RETAIN, or OPEN_PR_DIRTY_PRESERVE when its worktree is dirty, until PR disposition and clean session closeout.
- A same-name GitHub branch is only marked as containing the local tip when exact equality or local ancestry is proven.
- LOCAL_ONLY_REVIEW and detached rows must receive a named recovery ref, remote push, evidence archive, or explicit owner decision before cleanup.
- READY_CLEANUP rows still require session-close confirmation and explicit deletion authorization; this manifest does not authorize cleanup.
- Status counts use git status --porcelain=v1 -z --untracked-files=all. Ignored files are not counted.
