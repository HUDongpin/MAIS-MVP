This directory holds the append-only, pre-first-provider superseding registration for the offline implementation of the OpenAI GPT-5.6 Luna reference runner and the DeepSeek evaluation runner.

The registration preserves the frozen V5 design, California frame/sample, cluster audit, rights/privacy screens, taxonomy, labeling/adjudication method, thresholds, P0/P1/P2 rules, statistical analysis, and `INCONCLUSIVE_MACHINE_REFERENCE` decision ceiling.
