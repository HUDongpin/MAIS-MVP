# Shot Checklist

Use `/Users/peter/Desktop/MAIS-MVP` as the product source. Record from a clean demo browser profile and use demo data only.

## Browser Setup

- Set browser zoom to 100%.
- Use 1920x1080 capture if possible.
- Hide bookmarks bar and unrelated tabs.
- Use the same theme across most shots; dark mode is visually strong, but light mode may make captions easier. Pick one and stay consistent.
- Use English UI for the main recording. Capture one quick bilingual/language-toggle moment in the student segment.

## 00:00-01:00 Student Console

### Human Opening

- Student hand/notebook/laptop shot, 3-4 seconds.
- Student pauses on a math question; no personal papers or school identifiers.

### Product Flow

- `/` home page: MAIS brand and grade selector.
- Language toggle or bilingual UI moment.
- `/dashboard`: mastery circle, streak, selected grade, profile panel.
- `/personalized-learning`: progress metrics, assigned work, personalized analytics, recommended next lesson.
- `/learning-path`: roadmap/pathway view.
- `/lesson/quadratic-functions` or another visually strong lesson route.
- `/visualization-lab`: one interactive module with visible movement.
- `/practice`: one question, answer selection, feedback panel.
- AI Tutor: open the tutor panel and show guided hint/local-helper response.

## 01:00-01:30 Teacher Console

- `/teacher`: KPI cards, daily teaching queue, class learning status.
- `/teacher/analytics`: topic mastery heatmap, student risk list, frequent mistakes, intervention groups.
- `/teacher/live`: live classroom/session area with submitted count, correct rate, and reteach/continue signal.
- Optional close-up: Create follow-up button or intervention group, but do not click unless using safe demo data.

## 01:30-02:30 Founder Segment

### Founder Camera

- Medium shot of Dr. Peter Hu, eye line near camera.
- Clean background; optional blurred MAIS UI on monitor.
- Record 2-3 full takes, even if only 60 seconds is needed.
- Leave 2 seconds of silence before and after for easier editing.

### Build Process

- Editor or terminal showing project files, not secrets.
- Safe files to show: `app/`, `components/`, `components/teacher/`, `components/dashboard/`, `components/ai/`, `video-plan/`.
- Never show `.env`, `.env.local`, `.local/`, private messages, API keys, or real identities.

### Closing Montage

- Student dashboard.
- Teacher analytics.
- AI Tutor.
- Visualization lab.
- MAIS logo/end card.

## Shot Priorities

If time is tight, prioritize these:

1. Student dashboard personalized next step.
2. Visualization lab interaction.
3. Practice feedback and mistake review.
4. Teacher analytics risk/heatmap.
5. Founder direct-to-camera.

## B-Roll Safety

- Replace any real student names with demo names.
- Avoid showing actual inbox/message content unless it is seeded demo data.
- Blur or crop the browser URL if query parameters include session-like values.
