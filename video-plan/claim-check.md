# Claim Check Register

Purpose: keep the pitch ambitious without accidentally inventing evidence.

## Safe Current-Capability Claims

| Claim | Status | Evidence To Show |
|---|---|---|
| MAIS is a bilingual mathematics learning platform. | Current MVP capability | Home page, language toggle, bilingual copy. |
| MAIS supports P1-S6/S1-S6 style learning pathways. | Current MVP capability | Grade selector, learning path, roadmap. |
| Student dashboard shows mastery/progress/recommended next steps. | Current MVP capability | `/dashboard`, `/adaptive-learning`. |
| Practice records answers and shows feedback. | Current MVP capability | `/practice` and feedback panel. |
| Mistakes can become review targets. | Current MVP capability | Practice feedback/mistake-book flow if available. |
| AI Tutor is connected through a server-side route and can operate in configured or local-helper mode. | Current MVP capability | AI Tutor panel; avoid saying the live model is deployed unless API key is configured. |
| Learning analytics collects tagged learning signals. | Current MVP capability | Analytics cards and event-signal UI. |
| Teacher dashboard shows KPIs, mastery gaps, and action queues. | Current MVP capability | `/teacher`, `/teacher/analytics`. |
| Live classroom checks help teachers see submitted count, accuracy, and reteach/continue signal. | Current MVP capability | `/teacher/live`. |
| MAIS is pilot-ready. | Product-positioning claim | Safe if framed as readiness for pilot evaluation, not proof of completed pilot impact. |

## Vision-Led Claims That Must Stay Future-Framed

| Claim | Required Wording |
|---|---|
| MAIS can create prosperous learning environments. | Say "can help create" or "is designed to help create." |
| Every student can receive a responsive pathway. | Say "built for a future where" or "designed so that." |
| Teachers can intervene earlier. | Say "helps teachers act sooner" if showing current risk/intervention screens. |
| MAIS can scale beyond one classroom. | Say "designed for pilots and scalable evaluation" unless deployment metrics exist. |
| FII support can accelerate impact. | Say "With FII support, MAIS can move from prototype to pilots." |

## Avoid Unless Evidence Is Supplied

- Do not claim a number of students, schools, teachers, countries, pilots, users, retention gains, test-score gains, revenue, fundraising, or learning-outcome improvement.
- Do not claim "proven impact" unless backed by a study or pilot result.
- Do not claim "fully autonomous AI teacher." MAIS should be framed as supporting teachers and students.
- Do not claim live LLM deployment unless the final recording shows configured live mode.

## Final Claim Posture

Use this sentence if challenged:

MAIS is presented as a working MVP and pilot-ready learning environment, with vision-led claims clearly framed as future potential and intended pilot impact.
