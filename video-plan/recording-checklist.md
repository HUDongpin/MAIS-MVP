# Recording Checklist

## Before Recording

- Confirm current product route loads without visible errors.
- Use a demo account and seeded/demo data.
- Close unrelated apps and notifications.
- Disable browser autofill popups.
- Set microphone input and record a 10-second test.
- Prepare `voiceover-script.md` and `founder-teleprompter.md` in a separate window or tablet.

## Screen Recording

- Record each route as a separate clip, not one long rushed take.
- Hold each important UI state for at least 3 seconds.
- Move the cursor slowly; avoid circular cursor movement.
- Use deliberate scrolls and clicks.
- Capture alternate takes for dense screens with zoomed crops.

Suggested clip names:

- `01-home-grade-selector.mov`
- `02-student-dashboard.mov`
- `03-adaptive-learning-analytics.mov`
- `04-learning-roadmap.mov`
- `05-visualization-lab.mov`
- `06-practice-feedback.mov`
- `07-ai-tutor.mov`
- `08-teacher-dashboard.mov`
- `09-teacher-analytics.mov`
- `10-teacher-live.mov`
- `11-codex-build-process.mov`
- `12-founder-camera-take-1.mov`
- `13-founder-camera-take-2.mov`

## Founder Audio

- Use a dedicated microphone if available.
- Record in a quiet room with soft furnishings.
- Speak slightly slower than normal conversation.
- Smile lightly at the start and end of each paragraph.
- If a sentence fails, pause for 2 seconds and restart the sentence.

## Editing Pass

- Build the master timeline first.
- Add VO and founder audio.
- Add screen recordings under the VO.
- Add captions from `on-screen-captions.md`.
- Add SRT from `subtitles/mais-fii-master.en.srt`.
- Export the master, then create the three chapter exports from the same timeline.

## Final QA

- Watch the master once without sound: the story should still be understandable from captions and visuals.
- Watch once with sound but without reading the captions: the narration should feel clear and not rushed.
- Check every on-screen claim against `claim-check.md`.
- Confirm exact export durations in `export-guide.md`.
